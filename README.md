# 🚀 InvestHub

A platform where startup owners pitch their ideas and investors discover opportunities — all in one place.

## ✨ Features

- **Role-based access** — Register as an *Owner* to create pitches or an *Investor* to browse and explore
- **Pitch listings** — Browse all startup pitches on the home feed
- **Create a pitch** — Owners can submit detailed startup pitches
- **Pitch detail view** — Dive deep into any pitch
- **Auth & profiles** — Secure authentication powered by Supabase
- **Protected routes** — Dashboard and pitch creation are gated behind login

## 🛠 Tech Stack

- **React 19** + **Vite**
- **Tailwind CSS v4**
- **Redux Toolkit** — global state management
- **Supabase** — auth & database
- **React Router v7**
- **Lucide React** — icons
